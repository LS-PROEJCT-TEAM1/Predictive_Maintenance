# 가이드북 재현 및 4개 모델 비교

## 결론

가이드북의 공식 `pytorch_forecasting.NHiTS` 설정으로 재학습했지만, 가이드북에 기재된 `WeldingTest_03_NG` 성능은 재현되지 않았다. 반면 `WeldingTest_04_NG`에 사용한 가이드북의 2구간 Z-score는 기재된 F1 1.0을 정확히 재현했다.

가이드북의 N-HiTS 성능은 문서에 라이브러리 버전과 학습된 체크포인트가 제공되지 않아, 코드와 하이퍼파라미터만으로는 동일 결과를 보장할 수 없다.

## 재현한 가이드북 N-HiTS 설정

- 구현: `pytorch_forecasting.NHiTS`
- 입력 길이: 20
- 예측 길이: 10
- batch size: 128
- hidden size: 64
- learning rate: 0.04
- weight decay: 0.01
- loss: `MQF2DistributionLoss`
- max epochs: 30
- epoch당 학습 batch: 30
- Z-score threshold: 4.0
- RealPower < 1300인 값에 930.5 가산
- `WeldingTest_03_NG` 예측 결과를 12행 이동하여 라벨과 정렬

## 해석시 주의점

1. 위 표는 같은 테스트 행에서의 결과를 보여주지만, 학습·보정 조건까지 완전히 동일하지는 않다.
2. 가이드북 N-HiTS 코드는 테스트 파일 자체의 오차 평균·표준편차로 Z-score를 계산한다. 이는 실시간 초기 판정에서 바로 쓸 수 없는 테스트 적응적 평가이다.
3. 2구간 Z-score는 04번의 연속 이상에는 완벽하지만, 03번의 19개 고립 이상은 모두 놓친다.
4. 가이드북의 발표 수치를 RobustZ·LightGBM의 현재 수치와 바로 순위화하면 라이브러리 버전, 학습 표본, 임계값 보정, 평가 구간이 달라 결론이 왜곡된다.

## 공정한 최종 비교를 위한 권장 규칙

- 모든 모델은 같은 정상 학습 구간과 같은 보정 구간을 사용한다.
- 임계값과 오차 평균·표준편차는 학습 또는 보정 데이터에서만 고정한다.
- 테스트 파일의 통계량으로 임계값을 재조정하지 않는다.
- 모든 파일의 전체 행을 평가하고 같은 라벨을 사용한다.
- 행 단위 F1과 함께 이벤트 누락률, 정상 파일 오경보, 탐지 지연을 평가한다.
