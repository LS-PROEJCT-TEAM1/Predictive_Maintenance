## 1. 데이터 정제 / 전처리

원 데이터는 시험 1건당 231개 컬럼이다. 이 중 **셀 전압 176개(M**CV**) + 모듈 온도 32개(M**T**) = 208개**만 사용했다.

나머지 BMS 요약 컬럼(Voltage, Current, SOH, DV, Tmax 등)은 **OK 파일에서 전부 0으로 기록**되어 있다. 값이 없는 것이지 정상이라서 0인 것이 아니다. 이 컬럼을 그대로 쓰면 모델이 "DV가 0이면 OK"라는 규칙을 학습하게 되는데, 이는 데이터가 아니라 **파일 종류를 외우는 것**이라 제외했다 (교안 Ch39 데이터 누수).

| 처리 | 내용 | 결과 |
|---|---|---|
| 상수·미기록 컬럼 제거 | 231 → 208 컬럼 | 전 파일 동일 |
| 결측치 | 시계열 선형보간 후 전/후방 채움 | 원 결측 0건 |
| 중복 행 | 개수만 기록 (연속 측정에서는 자연 발생) | 0건 |
| 물리 범위 이탈 | 셀 전압 2.0~5.0V, 온도 -20~100℃ 밖은 센서 오류로 간주 | **Test06에서 854건** |
| 센서 고장 셀 | 한 셀 전체가 범위 이탈이면 같은 시점 다른 셀 중앙값으로 대체 | **Test06 M07 계열 1개 셀** |

Test06은 특정 셀이 전 구간 52V로 기록된 **전압 센서 고장** 사례다. 이 셀은 시간 방향 보간으로 채울 수 없어 별도 처리했고, 이 파일의 이상 원인 자체가 센서 이상일 가능성이 높다는 점을 기록해 둔다.

## 2. Feature Engineering

208개를 그대로 모델에 넣지 않고, 현장에서 해석 가능한 16개 지표로 요약했다 (교안 Ch13, Ch43).

- **셀 전압 분포**: 평균 / 최소 / 최대 / **편차(최대-최소)** / 표준편차 / **이상셀 개수(3σ 이탈 셀 수)** / 최대 z-score
- **모듈 온도 분포**: 평균 / 최소 / 최대 / **편차** / 표준편차
- **시간 변화**: 셀전압평균 변화율, 셀전압편차 이동평균 잔차(10시점), 모듈온도최대 변화율
- **운전 조건**: 방전 여부

핵심 설계는 **"절대 수준"이 아니라 "팩 내부의 불균형"** 을 본다는 점이다. 전압이 4.0V인지 3.9V인지는 충전 진행도에 따라 달라지지만, 같은 시점에 셀끼리 얼마나 벌어져 있는지는 팩이 달라도 의미가 유지된다.

## 3. 충방전별 전압·온도 특성 (EDA)

| 충방전 | 판정 | 셀전압 편차(V) | 셀전압 표준편차 | 이상셀 개수 | 모듈온도 최대(℃) | 모듈온도 편차(℃) |
|---|---|---|---|---|---|---|
| 충전 | OK | 0.0218 | 0.0050 | 0.28 | 25.80 | 1.57 |
| 충전 | NG | 0.0266 | 0.0057 | 1.81 | 29.38 | 2.19 |
| 방전 | OK | 0.0139 | 0.0032 | 0.17 | 30.33 | 2.06 |
| 방전 | NG | 0.0307 | 0.0037 | 1.80 | 32.55 | 2.80 |

읽어야 할 점 세 가지.

1. **충전과 방전은 기준이 다르다.** OK 기준으로도 셀전압 편차는 충전 0.0218V, 방전 0.0139V로 차이가 난다. 충방전을 섞어 하나의 임계값을 쓰면 안 되고, 모델에도 `방전여부`를 넣어야 한다.
2. **NG 판별에 가장 잘 듣는 건 '이상셀 개수'다.** OK 0.2~0.3개 vs NG 1.8개로 충·방전 모두에서 6배 이상 벌어진다. 절대 전압보다 셀 간 불균형이 판별력이 높다.
3. **온도는 NG에서 일관되게 높고 더 벌어진다.** 다만 절대 온도는 시험 환경(계절·설비)에 영향을 받으므로, 편차·표준편차 쪽이 더 안전한 변수다.

label과의 상관계수 상위는 모듈온도_최대(0.587), 모듈온도_최소(0.545), 모듈온도_편차(0.532) 순이다. 절대 온도의 상관이 높게 나오지만 이는 **NG 시험이 더운 조건에서 수행된 영향**이 섞여 있어, 그대로 믿으면 안 된다는 점을 4절에서 확인했다.

## 5. 모델 선정

### 선정: 교안 3σ 규칙 (주 모델) + PCA 이상탐지 (보조)

먼저 확인해야 할 점이 있다. **PCA는 교안에 나오지 않는다** (기획서 기술스택에만 있음). 교안 Part 5는 회귀/분류와 Decision Tree·Random Forest, Part 6 Ch46은 3σ·IQR·이동평균 잔차 기반 이상치 탐지를 다룬다. 그래서 교안 Ch46 방식만으로도 같은 문제를 풀 수 있는지 함께 검증했다.

**교안 Ch46 코드 46-5(평균 + 3×표준편차)를 정상 데이터에만 적용해 임계값을 만들고, 불량 유형별로 OR 결합한 규칙**의 성능이다.

| 변수(단독 3σ 규칙) | 임계값 | Precision | Recall | F1 |
|---|---|---|---|---|
| 모듈온도_편차 | 3.088 ℃ | **1.000** | 0.689 | 0.816 |
| 셀전압_최대z | 3.325 | 0.258 | 0.452 | 0.328 |
| 이상셀_개수 | 1.411개 | 0.303 | 0.557 | 0.392 |
| 셀전압_편차 | 0.0502 V | 1.000 | 0.031 | 0.060 |

**모듈온도_편차 OR 셀전압_최대z** 로 묶으면 (Test07 제외 기준) **Accuracy 0.974 / Precision 0.953 / Recall 1.000 / F1 0.976** 으로, PCA(0.716)와 Random Forest(0.953)를 모두 앞선다. 두 규칙이 서로 다른 불량 유형을 담당하기 때문이다.

- 모듈온도_편차 → Test08(온도 불균형) 2,396시점 전량 탐지, 오탐 0
- 셀전압_최대z → Test06(전압 센서 고장) 854시점, Test07(셀 전압 급락) 227시점 전량 탐지

### 최종 정리

| 판단 기준 | 교안 3σ 규칙 | PCA 이상탐지 | Decision Tree | Random Forest |
|---|---|---|---|---|
| 교안 수록 | **Ch46 코드 46-5** | 미수록 | Ch40 | Ch40 |
| Precision (Test07 제외) | **0.953** | 0.716 | 0.370 | 0.953 |
| Recall (Test07 제외) | **1.000** | 1.000 | 0.970 | 0.737 |
| 학습에 NG 라벨 필요 | **불필요** | 불필요 | 필요 | 필요 |
| 새 불량 유형 대응 | 규칙 추가 필요 | **자동 탐지** | 학습한 유형만 | 학습한 유형만 |
| 과적합 | **없음(임계값 2개)** | 낮음 | 심함 | 심함 |
| 결과 설명 | **"온도 편차 3.1℃ 초과"로 설명** | 기여 변수 추적 필요 | 규칙으로 설명 | 중간 |
| 이상 점수 산출 | 초과량으로 환산 | **Q·T² 연속값** | 확률값 | 확률값 |

**교안 3σ 규칙을 주 모델로 선정한 이유**는 세 가지다.

1. **성능이 가장 높다.** Precision 0.953 / Recall 1.000으로, 놓치는 이상 구간이 없으면서 오경보도 가장 적다.
2. **현장에서 설명된다.** "정상 팩의 모듈 온도 편차는 평균 2.07℃, 3σ 상한 3.09℃인데 이 팩은 4.56℃"처럼 담당자에게 근거를 그대로 제시할 수 있다. 학습 파라미터가 아니라 임계값 2개가 전부라 과적합 여지가 없다.
3. **교안 범위 안이다.** Ch46 코드 46-5를 그대로 쓰므로 팀 누구나 검토·수정할 수 있다.

**PCA를 보조로 두는 이유**는 규칙이 담당하지 않는 **새로운 불량 유형** 때문이다. 3σ 규칙은 "온도 편차"와 "셀 전압 이탈" 두 유형만 본다. 처음 보는 형태의 이상(예: 특정 모듈만 충전 속도가 느려지는 패턴)은 규칙에 걸리지 않지만 PCA는 "정상 패턴에서 벗어남"으로 잡아낸다. 규칙이 1차 판정, PCA가 미분류 구간 2차 확인 구조가 맞다.

**Decision Tree / Random Forest는 이번 데이터에서는 부적합**하다. 학습 1.000 / 테스트 0.45~0.71의 과적합이고, 교차검증 표준편차가 0.4다. 시험 9건에 불량 유형 5개가 전부 달라 학습할 공통 패턴이 없다. 시험 건수가 늘어나면 재검토할 수 있다.

### 운영 설정

- 1차 규칙(교안 Ch46): 모듈온도_편차 > 3.088℃ **또는** 셀전압_최대z > 3.325 → 이상
- 임계값은 정상(OK) 학습 데이터의 평균 + 3×표준편차로 산출
- 2차 PCA: 정상(OK) 학습 데이터로만 적합 → 주성분 6개(누적 설명분산 97.65%)
- 임계값: 정상 데이터 99% 분위수 (Q=1.839, T²=26.146)
- 이상 판정: 임계값을 **연속 10시점 이상** 초과할 때만 이상 구간으로 확정 (단발 잡음 억제, 교안 Ch46)
- 임계값과 연속 길이는 **학습 데이터에서만** 탐색했다 (`03b_PCA_임계값_탐색.csv`)

## 7. 한계와 다음 작업

1. **셀 단위 정답 라벨이 없다.** 기획서의 "이상 셀 판별 Precision 0.7"은 현재 데이터로는 직접 검증할 수 없어, **시점 단위 Precision으로 대체 측정**했다. 셀 단위 지표가 필요하면 별도 라벨링이 있어야 한다.
2. **Test07의 라벨 정의가 다른 파일과 다르다.** 팀 차원에서 "이상 구간을 언제부터로 볼 것인가"를 통일해야 지표가 안정된다. 현재 전체 지표(Precision 0.38)와 Test07 제외 지표(0.72)의 차이 대부분이 여기서 온다.
3. **시험 9건은 모델 검증에 부족하다.** 교차검증 표준편차 0.4가 그 근거다. 지도학습(DT/RF)을 주 모델로 쓰려면 시험 건수를 늘려야 한다.
4. Dash 연동은 `07_테스트_예측결과.csv`(시점별 이상 점수·예측)와 `06_이상셀_순위.csv`를 그대로 읽으면 된다.
