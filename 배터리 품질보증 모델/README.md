셀 전압 176개 + 모듈 온도 32개 = 208개 시계열 변수로 배터리팩의 **이상 셀·이상 구간**을 탐지한다.

## 결론

**PCA (Hotelling T² · SPE) 채택.** 테스트 5개 시험(10,770시점) 기준 F1 0.9866, 파일 단위 교차검증 F1 0.8615로 두 지표 모두 1위이며, 세 가지 불량 유형을 모두 잡는 유일한 모델이다.

| 순위 | 모델 | 테스트 F1 | 교차검증 F1 | 불량 3유형 커버 | 라벨 필요 |
|---|---|---|---|---|---|
| **1** | **PCA (T²·SPE)** | **0.9866** | **0.8615** | **3 / 3** | 불필요 |
| 2 | T²+SPE 결합지표 | 0.9866 | 0.8194 | 3 / 3 | 불필요 |
| 3 | Random Forest | 0.8599 | 0.6443 | 2 / 3 | 필요 |
| 4 | Isolation Forest | 0.6698 | 0.6062 | 1 / 3 | 불필요 |
| 5 | LSTM Autoencoder | 0.4370 | 0.3762 | 1 / 3 | 불필요 |

### 불량 유형별 탐지율 (TP / 실제 이상)

| 불량 시험 | 유형 | PCA | RF | IF | LSTM |
|---|---|---|---|---|---|
| Test06_NG_chg | 전압 센서 고장 | **1.000** | **0.000** | 1.000 | 0.999 |
| Test07_NG_dchg | 셀 전압 급락 | 0.639 | 1.000 | 0.194 | 0.467 |
| Test08_NG_chg | 모듈 온도 불균형 | **1.000** | 1.000 | 0.358 | 0.007 |

Random Forest는 학습에 없던 유형(Test06)을 **전혀 잡지 못한다**. 시험 9건에 불량 유형이 모두 달라 지도학습으로는 일반화되지 않는다는 근거다.

### T² vs SPE

| 지표 | 의미 | Precision | Recall |
|---|---|---|---|
| **SPE 단독** | 정상 상관 구조로 설명되지 않는 잔차 | 0.9886 | **0.9764** |
| T² 단독 | 정상 구조 안에서 벗어난 거리 | 0.8688 | 0.4648 |

탐지력의 대부분이 SPE에서 나온다. 배터리 불량은 값이 범위를 벗어나기 전에 **셀·모듈 간 관계가 먼저 깨지는** 형태로 나타난다.

## 방법

### 전처리

원 데이터 231컬럼 중 **셀 전압(M**CV**) 176 + 모듈 온도(M**T**) 32 = 208개**만 사용한다. BMS 요약 컬럼(Voltage, Current, SOH, DV 등)은 OK 파일에서 전부 0으로 기록되어 있어, 그대로 쓰면 모델이 "DV=0이면 OK"라는 파일 종류 자체를 외운다(데이터 누수).

- 물리 범위 이탈(셀 전압 2.0~5.0V, 온도 −20~100℃ 밖)은 센서 오류로 보고 시계열 보간
- 한 셀 전체가 이탈이면 같은 시점 다른 셀의 중앙값으로 대체 (Test06의 52V 센서 고장 사례)

### Feature

208개를 그대로 넣지 않고 **팩 내부의 상대적 특성**으로 요약한다. 절대 전압·온도는 충전 진행도와 시험 환경에 따라 달라져 새 팩에 적용되지 않는다.

- 셀 전압: 편차(max−min) / 표준편차 / 3σ 이탈 셀 수 / 최대 z-score
- 모듈 온도: 편차 / 표준편차
- 시간 변화: 셀전압평균 변화율, 셀전압편차 이동평균 잔차, 모듈온도최대 변화율

### 학습·평가 분리

**파일(시험) 단위로 분리**한다. 같은 시험의 앞뒤 시점을 학습과 평가에 나눠 담으면 성능이 부풀려진다.

- 정상 기준: `preprocessed/train` 10개 파일(충전 5 + 방전 5) 56,805행 — 비지도 모델은 이것만 학습
- 지도학습 추가: Test05(NG 충전), Test09(NG 방전)
- 평가: Test03, Test04(정상) / Test06, Test07, Test08(불량)

교차검증은 fold별 점수를 평균내지 않고 **Out-of-Fold 예측을 모아 한 번에 계산**한다(단일 값).

### PCA 운영 설정

- 정상 56,805행으로 적합 → 주성분 6개, 누적 설명분산 97.51%
- 관리한계: 정상 데이터 99% 분위수 → **T² > 20.427 또는 SPE > 2.046**
- 임계값을 **연속 10시점 이상** 초과할 때만 이상 구간으로 확정(단발 잡음 억제)
- 관리한계와 연속 길이는 학습 데이터에서만 탐색

## 한계

- 셀 단위 정답 라벨이 없어 기획서의 "이상 **셀** 판별 Precision"은 시점 단위로 대체 측정했다.
- Test07은 NG 팩인데 라벨이 마지막 227시점(4.9%)에만 붙어 있다. 모델이 그 앞부터 감지한 이상(M02CV01 셀 z-score 5.85)이 오탐으로 계산될 수 있다.
- LSTM Autoencoder는 CPU 멀티스레드에서 학습이 완전히 재현되지 않아 실행마다 Recall이 달라진다(0.28~0.38).
- 정상 기준 데이터를 더 늘릴 여지가 있다(현재 10개 / 전체 102개).
