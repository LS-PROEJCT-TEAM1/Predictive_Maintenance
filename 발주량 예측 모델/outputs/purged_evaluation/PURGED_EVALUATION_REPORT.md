# 누수 제거 D+3 수요예측 재평가

## 최종 결론

- **전체 운영 예측기:** 3일 이동평균
- **학습형 모델 1위:** XGBoost
- 이 결론은 최종 holdout을 보지 않고, 시간 누수를 제거한 3-fold expanding walk-forward의 통합 MAE로 선정했다.
- 원본 Total과 시간대별 합계의 두 시나리오에서 순위가 동일하게 재현됐다.
- 최종 holdout에서는 CatBoost가 가장 낮은 MAE를 보였지만, holdout은 모델 선택에 사용하지 않은 최종 확인 자료이므로 CatBoost를 다시 선택하는 근거로 사용하지 않는다.

## 평가 설계

- 예측 horizon: 기준일로부터 D+3
- 입력 시퀀스: 동일 부품의 연속 3일
- 모델 선택: 3-fold purged expanding walk-forward MAE
- 엄격한 경계: `train target < validation origin`, `validation target < test origin`
- 최종 holdout: 마지막 7개 목표일(2021-10-25~2021-11-01), 모델 선택과 무관하게 보존
- 공통 모델: XGBoost, LightGBM, CatBoost, LSTM, 3일 이동평균
- 참고 기준: 원본 D+3 계획량

## 데이터 범위와 제외

- 원본 부품: 117개
- 전체 평가에서 제외: Part 115 한 개(유효한 연속 3일 시퀀스가 최소 기준 미만)
- 전체 평가 가능 부품: 116개
- 반복검증 공통 표본: 1,614건, 등장 부품 113개
- 최종 holdout 공통 표본: 764건, 등장 부품 111개
- 초기 fold에서 학습 이력이 아직 없었던 34개 표본은 모든 모델을 같은 조건으로 비교하기 위해 해당 fold에서만 제외했다. 해당 부품을 전체 기간에서 영구 제외한 것은 아니다.
- 계획량 0과 실제량 0은 결측치로 처리하지 않고 모두 유지했다.

## 수량 정의 민감도

원본 Total과 시간대별 합계가 다른 원본 행은 D 31건, D+3 149건, D+4 136건이다. D+1과 D+2는 모든 행에서 동일하다. 두 시나리오는 정답 자체가 다르므로 MAE 절대값만으로 어느 정의가 옳은지 결정하지 않는다. 업무상 공식 수량 정의가 확정될 때까지 두 결과를 민감도 분석으로 함께 보존한다.

## 검증 결과

- 저장 예측값으로 MAE, RMSE, WAPE, Bias, R² 재계산 일치
- 8개 분할 모두 엄격한 purge 경계 통과
- XGBoost, CatBoost, LightGBM 저장 모델 재로딩 성공
- LightGBM 모델은 LF 줄바꿈으로 저장해 Windows CRLF 재현성 문제 해결
- 전체 자동 검사 9개 통과
