# 최종 D+3 수요예측 모델 평가

## 결론

- 최종 1위 모델은 **3-day Moving Average**이다.
- 1위 선정 기준은 공통 테스트 표본의 **MAE 최소화**이다.
- Part115는 유효한 3일 시퀀스가 5개로 최소 기준 10개 미만이어서 모든 모델에서 제외했다.

## 평가 조건

- 모델: XGBoost, LightGBM, CatBoost, LSTM, 3일 이동평균
- 대상: 116개 부품, 제외: Part 115
- 시퀀스: 연속 3일 입력, 마지막 입력일 기준 정확히 D+3 실제 수량
- 시간 분할: 학습 70%, 검증 10%, 테스트 20%의 목표 날짜 순서
- 테스트 기간: 2021-10-23~2021-11-01
- 테스트 표본: 976개, 활동 부품: 111개
- D, D+1, D+2, D+3, D+4는 시간대별 수량 합계 사용
- 계획량 0과 실제량 0은 삭제하지 않음
