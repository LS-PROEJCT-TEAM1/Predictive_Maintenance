# 발주량 재학습·검증 결과 — 2026-09-27

운영 기본은 **7일 이동평균**, 학습형 보조는 **LSTM**이다. 9가지 방법을 같은 시간순 평가 행에서 비교하고 선택을 고정했다. 모든 모델을 실제 재학습했으며 Firestore 업로드는 실행하지 않았다.

## 실제 결과

CV는 12개 목표일·1,289행·112부품, 마지막 회고 평가는 7개 목표일·750행·109부품이다. 수치가 작을수록 오차가 작다. 과거 실험과 표본/분할이 달라 이전 점수 대비 개선율을 제시하지 않는다.

## 감사 지적에 대한 보완

- 원본 17,364행·84열을 확인했다. 동일 부품·시각 충돌 306그룹/612행의 Part 21·26은 격리했다. 원본은 그대로 보존하고 충돌 행을 별도 CSV로 저장했다. 남은 115부품의 일별 5,380행을 사용한다. 0 수량은 남기며 누락 2021-10-31을 0으로 보간하지 않는다. Part 115의 하드코딩 제외도 없앴다.
- 최근값·7일 평균 기준을 추가했다. 트리 3종, LSTM, 연관 LightGBM을 내부 검증으로 조정했다. 확장 특징은 같은 목표일의 계획 수정량과 최근 7일 이력을 포함한다. LSTM 손실은 원 수량 MAE에 맞췄다.
- 내부 검증을 5개 목표일로 넓혔고 4개 목표일씩 3회 외부 검증했다. 학습 목표일이 검증 입력 기준일을 넘지 않는지 검사한다. 인코더·스케일러·상관 부품은 각 학습 범위에서만 계산한다. 미학습 부품도 내부/외부 평가에 포함하고 최근값으로 대체한다.
- 부품별 회고 정답을 보고 모델을 고르던 정책을 제거했다. 현재 모든 부품은 같은 CV 선정 정책을 쓴다. 연관 모델은 CV에서 개선되지 않아 토글이 비활성화된다. 다른 목표일의 연관 예측을 끌어오는 동작도 없앴다.
- 학습/CSV 추론 특징 계약을 공유한다. 입력은 3~60일, 최근 3일 연속, 8일 권장이다. 격리 부품·음수·무한대·중복 날짜를 거부한다. 신규 부품 대체와 이력 부족을 응답에 표시한다.
- 마지막 기간을 새로운 독립 검증이라고 부르지 않는다. 이미 본 자료의 **회고 평가**다. 이 기간 정답으로 학습하거나 정책을 재선정하지 않았다.

## 아직 주장할 수 없는 것

원본 Total 기준에서는 7일 평균이 1위지만 시간대 합계 기준에서는 LSTM(34.6762)이 근소하게 앞선다. 수량 정의에 순위가 민감하다. 주 분석은 사전 정의한 원본 Total을 유지하며 성능이 낮아 보이는 정의를 사후 폐기하지 않았다.

7일 평균과 3일 평균의 CV MAE 차이에 대한 목표일 bootstrap 95% 구간은 **-6.95~+5.21개**로 0을 포함한다. 7일 평균의 우월성이 통계적으로 확정됐다고 볼 수 없다. 약 50일 데이터로 장기 계절성이나 현장 일반화 성능을 보장할 수 없다.

CV 잔차의 단측 90% 분위수는 66.1429개, 회고 구간 커버리지는 95.07%다. 정책 선택과 보정에 같은 CV를 썼으므로 낙관적일 수 있다. 안전재고·최적 발주량·90% 서비스 수준이 아니다. 최신 화면의 과거 합산량도 실시간 미래 예측으로 오해하면 안 된다.
