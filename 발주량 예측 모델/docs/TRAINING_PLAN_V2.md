# 발주량 학습·검증 계약 audited_v2

## 원본과 예측 시점

KAMP 공급망 데이터 `data.xls`의 17,364행·84열·117부품을 사용한다. 가이드북의 당일 발주 확정 계획 의미를 따른다. 일별 마지막 로그가 확정된 후 3일 뒤 최종 ERP 계획량을 예측한다. 0은 유효한 수량이다. 결측 달력일은 0으로 간주하지 않는다. 중복 시각에 상충 값이 있는 Part 21·26은 전체 격리한다. 원본 삭제·임의 정정·마지막 행 임의 선택은 하지 않는다.

원본 Total을 주 분석의 수량 정의로 사전 고정한다. 시간대 합계를 별도 민감도 분석하고 오류가 작은 쪽으로 정답 정의를 바꾸지 않는다. 두 수량 정의의 우승 모델이 다를 수 있음을 보고한다.

## 특징과 비교

필수 입력은 같은 부품의 최근 연속 3일 `actual_d`, `plan_d3`, `plan_d4`, `plan_d5`다. 마지막 입력 날짜 이후 자료는 사용하지 않는다. 기본 특징은 3일 이력·요일·월·주말이다. 확장 특징은 지난 7일 평균/편차·7일 전 값·관측일 수·동일 목표일의 계획 수정량/비율·최근 변화량이다. 학습과 추론은 `src/demand_contract.py`를 공유한다.

최근값, 3일 평균, 7일 평균, 원본 D+3 계획을 기준으로 XGBoost·LightGBM·CatBoost·LSTM·연관 부품 LightGBM을 비교한다. 트리 기본/확장 특징과 크기를 내부 검증으로 선택한다. LSTM은 원 수량 MAE에 비례하는 L1 손실을 사용한다. 스케일러·인코더·결측 대체기는 학습 자료에만 적합한다. 미학습 부품은 모든 내부/외부 검증과 실제 추론에서 최근값 대체 규칙을 적용한다.

연관 부품은 각 학습 구간 안에서 최소 7개 공통 관측일의 양의 Pearson 상관 상위 3개를 선택한다. 최종 모델을 재적합할 때도 첫 평가 예측시점 전으로 제한한다. 이는 검증된 BOM·공동사용 관계가 아니다.

## 시간순 분할과 선택

외부 검증은 4개 목표일씩 3회 반복한다. 각 외부 구간의 이전 자료에서 5개 목표일을 내부 검증으로 사용한다. 학습 목표일은 내부 검증의 첫 입력 기준일보다 반드시 이르고, 내부 검증 및 재적합 목표일은 외부 평가의 첫 입력 기준일보다 반드시 이르다. D+3의 달력 간격을 직접 검사한다.

내부 검증으로 설정·학습 횟수를 선택한 뒤, 외부 평가 시작 전에 확보된 라벨로 재적합한다. 전체 방법과 학습형 보조 모델은 외부 CV의 합산 MAE, 동률이면 RMSE로 선택한다. 마지막 기간 평가 전에 선택 결과를 파일로 기록한다. 부품별 회고 성능으로 모델을 선택하지 않는다. 연관 모델 토글은 전역 CV 개선 2%와 해당 부품 CV 8행 이상 조건으로 제한한다.

마지막 7개 목표일은 종전 실험에서 이미 관측한 기간이다. 이번 코드에서 선택용으로 쓰지 않아도 새로운 독립 시험이 되지는 않는다. **회고 평가**로만 보고한다. 현재 배포 모델은 그 기간의 정답으로 학습하지 않은 재적합 모델이다.

## 지표와 한계

MAE·RMSE·WAPE·Bias·R²를 공통 행에서 보고하고 부품별·fold별·급증 구간을 진단한다. 급증 구간은 회고 진단이며 운영 경보 임계값이 아니다. 선택된 ML/LSTM은 설정을 고정하고 seed 137·2026으로 안정성을 검사한다(기준 seed 42). CV 목표일 단위 bootstrap으로 평균 기준모델 간 차이의 불확실성을 보고한다.

CV 잔차의 단측 90% 경험적 분위수를 참고 상한으로 사용한다. 이 CV로 정책도 골랐으므로 독립 보정이나 90% 서비스 수준 보장으로 해석하지 않는다. 재고·납기·손실 비용이 없어 최적 발주·안전재고 계산으로 표현하지 않는다.

실행 전 계획은 `outputs/audited_v2/training_plan_v2.json`, 실행 및 코드·원본 해시는 `run_manifest.json`, 실제 분할은 `source_total/split_audit.csv`에 남긴다. 완료 버전은 덮어쓰지 않으며 재실험은 기존 산출물을 보존한 새 버전으로 진행한다. 원본 충돌을 해결하려면 원자료 제공자의 정정이 필요하고 신규 일반화 성능에는 새 기간 데이터가 필요하다.
