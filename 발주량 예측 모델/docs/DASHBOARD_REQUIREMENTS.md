# 발주량 예측 대시보드 기능 정의

## 사용자

- 발주 담당자: 부품별 D+3 예상 수량과 현재 계획 차이를 확인한다.
- 생산·구매 관리자: 전체 수요 추이와 모델 안정성을 확인한다.
- 데이터 담당자: 데이터 누락, 부품별 데이터 기간, 모델 버전을 확인한다.

## 구현 화면

### 전체·부품별 조회

- 부품 선택
- 목표 날짜 범위 선택
- 실제 수량, CatBoost 예측, 3일 이동평균, D+3 계획값 비교
- 선택 범위의 실제 수량 합계와 CatBoost MAE

### 모델 성능

- 전체 holdout MAE 비교
- 부품별 MAE, RMSE, WAPE, Forecast Bias, R²
- expanding walk-forward fold별 결과 파일 제공
- CatBoost가 학습형 holdout 1위이고 이동평균이 전체 holdout 및 반복검증 1위임을 구분

### 계획 대비 확인 대상

- 권장 예측이 D+3 계획보다 20% 또는 10개 이상 높은 부품
- 권장 예측이 D+3 계획보다 20% 또는 10개 이상 낮은 부품
- 이는 재고 경보가 아니라 계획과 예측의 차이를 확인하는 목록

### 새 데이터 추론

- 같은 부품의 연속 3일 CSV 업로드
- CatBoost 예측과 3일 이동평균을 함께 표시
- 학습에 없던 부품은 3일 이동평균으로 자동 fallback
- 목표 날짜는 마지막 입력일의 D+3로 계산

## 추후 Firestore 연결 시 추가할 기능

- 최신 추론 결과 저장과 이력 조회
- 사용자별 관심 부품 목록
- 계획 대비 차이 확인 상태와 담당자 메모
- 센싱 데이터 연결 후 이상 상태와 수요 예측의 동시 표시

현재 데이터에는 재고량, 안전재고, 단가, 조달 리드타임이 없다. 해당 자료가 추가되기 전에는 부족 위험, 재고 비용, 긴급 발주 여부를 확정값으로 표시하지 않는다.
