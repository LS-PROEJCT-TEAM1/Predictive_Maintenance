# 예지보전 보완·재학습 계획 v3

이 계획은 보완 후 모델 적합 전에 고정한다. 시험 파일은 모두 과거 관측 자료이므로 재사용 파일 회고 평가로 표시한다. 외부 일반화와 사전 고장 예측은 미검증이다.

1. 필수 열·숫자 유한값·음수·PageNo·날짜를 검증한다. 새 CSV 추론은 완전한 39행 사이클과 엄격한 시간 증가를 요구한다. 입력 오류는 정상 판정과 분리한다.
2. 원본을 보존한다. 정상 이력 중 사이클 내부 시간 역전/동일 시각 또는 출력 0이 있는 사이클을 사유별 격리한다. 나머지 완전 사이클을 시작 시각 순으로 정렬하고 앞 70% 적합/뒤 30% 임계값 보정으로 나눈다. 원본 행 ID를 유지한다.
3. 주 평가 파일 역할은 이전 비교를 위해 유지한다: 개발 01_OK+03_NG의 파일별 70/30 사이클 분리, 회고 시험 02_OK+04_NG. 정상 이력은 02_OK보다 미래 자료도 포함하므로 전체 미래 시점 검증이라고 표현하지 않는다.
4. 기존 지도 3종·비지도 3종을 동일 조건으로 재적합한다. 정상 보정 99.9% 임계값 유지. 지도 임계값은 개발 validation에서만 선택한다. 마지막 시험 평가 전에 validation 결과와 선택을 저장한다.
5. 후보 동률 규칙: 이벤트 미탐, 행 FN, 오경보 이벤트, F1, 행 FP 순. 동률이면 사전 정의 단순성 순서 RobustPhaseZ → LogisticCurrent → LightGBMResidual → RandomForestCurrent → IsolationForestNormal → LogisticHistoryOnly. 학습시간으로 선택하지 않는다. 운영 비지도/지도 선택도 각각 validation에서 같은 규칙으로 결정한다.
6. 경보 정책 v3: 선택 지도·비지도 판정의 OR. 한 행 초과부터 경보 시작, 정상 행에서 종료, 인접 경보는 사이클 경계를 넘어 연속 이벤트로 묶되 수집 공백 120초 초과에서는 분리한다. 사후 양방향 평활화·최소지속 필터·라벨 기반 병합은 사용하지 않는다. 사이클 판정은 한 행 이상 경보, 파일 판정은 한 사이클 이상 경보로 정의한다.
7. 행·사이클·파일·이벤트 지표와 조합별 정책 지표를 저장한다. 센서 행 사이의 0초 초과 120초 이하 간격만 관측 가동시간으로 합산하여 오경보/관측시간을 보조 지표로 보고한다. 실제 설비 가동시간과 같다고 주장하지 않는다. 기존 행 FPR≤1% 외에 임의 현장 승인 기준을 추가하지 않는다.
8. 고정된 보조 검증: 반대 파일 방향(단일 사건 분할 한계 표시), NG03 개발 비율 50/60/70%의 민감도, 정상 보정 분위수 99.5/99.9/99.95% 민감도. 결과로 주 모델/임계값을 재선정하지 않는다.
9. 별도 정상 전용 시간 검증: 01_OK 최초 시점 이전 정상 이력만 70/30으로 분리하여 RobustPhaseZ를 적합·보정하고 이후 4개 파일을 평가한다. 사전 지정 기준모델 진단이며 주 모델 선택에 사용하지 않는다.
10. 계획/입력/코드/저장 모델 해시와 실행 환경을 기록한다. 새 결과로 화면·로컬 시드를 갱신하고 외부 DB에 업로드하지 않는다.

현장 배포 승인 조건은 새 사건 자료, 설비 단위/범위 확인, 점검 비용 기반 오경보 기준이다. 현재 사례 수 부족은 재학습으로 해소됐다고 표시하지 않는다.
