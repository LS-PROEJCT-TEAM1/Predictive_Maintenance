# noto_d web fonts

The `noto_d` alias follows the LS website's Noto Sans KR DemiLight definition.
Medium/Bold files preserve the dashboard's typographic weight hierarchy.

Source stylesheet: https://www.lsholdings.com/assets/css/font.css?v=1
Font files: https://www.lsholdings.com/assets/font/notokr-demilight.woff
(and notokr-medium.woff / notokr-bold.woff in the same directory).
