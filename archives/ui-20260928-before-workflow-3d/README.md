## 변경 직전으로 복구할 때

- `rollback.zip`: 개편 직전의 frontend, backend 소스/에셋과 DESIGN.md,
  requirements.txt, run_local.py. 이미 수정되어 있던 작업 내용까지 포함합니다.
- `snapshot.json`: 보관 시각, Git 기준 커밋, 파일별 SHA-256. 모델·원본 데이터·
  Firestore·비밀 설정은 이번 UI 개편에서 변경하지 않아 ZIP에 포함하지 않았습니다.
- `revision.json`: 이번 개편으로 변경/추가된 파일과 완료 시점 해시.
- `restore.py`: 먼저 실행하면 해시 검사와 복구 대상만 표시합니다. 실제 복구는
  로컬 서버를 종료한 뒤 `--restore`를 붙입니다. 이후 수정된 파일이 있으면 중단하며,
  복구 직전 내용도 별도 ZIP으로 보관합니다. Git 브랜치/커밋은 변경하지 않습니다.

프로젝트 루트에서:

```powershell
.venv/Scripts/python.exe archives/ui-20260928-before-workflow-3d/restore.py
# 실제 복구가 필요할 때만:
.venv/Scripts/python.exe archives/ui-20260928-before-workflow-3d/restore.py --restore
```

보관 폴더 자체는 앱 메뉴나 Copilot 검색 문서에 자동으로 등록하지 않았습니다.

  되돌리는 복구 사전 검사를 통과했습니다. 실제 복구는 실행하지 않았습니다.
